这里通常会显示登录卡片。若上方空白、没有登录表单，说明登录组件在构建期注入失败
（构建日志会有 login-page: 前缀的警告），常见原因是 source/_data/auth.yml
缺失或条目格式错误。可用 node tools/auth-tool.mjs list 检查账号数据，
修复后重新执行 npx hexo generate 即可恢复。
